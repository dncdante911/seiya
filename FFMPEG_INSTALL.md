# Установка FFmpeg для автоматической конвертации видео

FFmpeg - это утилита для обработки видео, которая позволяет автоматически конвертировать загружаемые видео в формат MP4 H.264, который поддерживается всеми современными браузерами.

## Зачем нужен FFmpeg?

**Без FFmpeg:**
- MKV, AVI, MOV и другие форматы могут не воспроизводиться в браузере
- Пользователи увидят ошибку воспроизведения
- Придется вручную конвертировать видео перед загрузкой

**С FFmpeg:**
- ✅ Автоматическая конвертация при загрузке
- ✅ Любой формат конвертируется в MP4 H.264
- ✅ Гарантированное воспроизведение во всех браузерах
- ✅ Оптимизация размера файла

## Установка FFmpeg

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install ffmpeg -y
```

Проверка установки:
```bash
ffmpeg -version
```

### CentOS / RHEL

```bash
# Добавляем EPEL репозиторий
sudo yum install epel-release -y

# Устанавливаем FFmpeg
sudo yum install ffmpeg ffmpeg-devel -y
```

### cPanel / WHM

```bash
# Через SSH как root
yum install ffmpeg ffmpeg-devel -y
```

Или через WHM:
1. WHM → Software → Module Installers
2. Найдите "FFmpeg" и установите

### Plesk

```bash
# Через SSH
sudo apt install ffmpeg -y  # Для Ubuntu/Debian
# или
sudo yum install ffmpeg -y  # Для CentOS
```

### Shared Hosting

Если у вас shared хостинг без SSH доступа:
1. Свяжитесь с технической поддержкой хостинга
2. Попросите установить FFmpeg
3. Альтернатива: используйте облачный сервис конвертации (например, Cloudinary, AWS MediaConvert)

### macOS

```bash
# Через Homebrew
brew install ffmpeg
```

### Windows Server

1. Скачайте FFmpeg с официального сайта: https://ffmpeg.org/download.html
2. Выберите Windows builds
3. Распакуйте в `C:\ffmpeg`
4. Добавьте `C:\ffmpeg\bin` в PATH

## Проверка работы

После установки FFmpeg, система автоматически начнет конвертировать загружаемые видео.

### Тест конвертации:

1. Зайдите в админку: `/admin/portfolio.php`
2. Загрузите видео в формате MKV или AVI
3. После успешной загрузки вы увидите сообщение: **"Видео автоматически конвертировано в MP4 для лучшей совместимости"**

### Если FFmpeg не установлен:

Вы увидите предупреждение: **"FFmpeg не установлен. Рекомендуется установить для лучшей совместимости с браузерами."**

Видео все равно будет сохранено в оригинальном формате, но может не воспроизводиться в некоторых браузерах.

## Технические детали

### Параметры конвертации

Система использует следующие параметры FFmpeg для оптимального качества и совместимости:

```bash
ffmpeg -i input.mkv \
  -c:v libx264 \        # H.264 видео кодек
  -preset medium \       # Баланс скорости и качества
  -crf 23 \             # Качество (18-28, меньше = лучше)
  -c:a aac \            # AAC аудио кодек
  -b:a 128k \           # Битрейт аудио 128 kbps
  -movflags +faststart \ # Быстрый старт воспроизведения
  output.mp4
```

### Поддерживаемые форматы для конвертации:

- MKV → MP4
- AVI → MP4
- MOV → MP4
- WMV → MP4
- FLV → MP4
- MPEG/MPG → MP4
- 3GP → MP4

Форматы **MP4**, **WebM**, **OGG** не конвертируются, так как уже поддерживаются браузерами.

## Устранение проблем

### FFmpeg установлен, но конвертация не работает

1. Проверьте, доступен ли FFmpeg для PHP:
```bash
sudo -u www-data which ffmpeg
# или
sudo -u apache which ffmpeg
```

2. Проверьте права на запись в папку uploads:
```bash
chmod -R 755 uploads/
chown -R www-data:www-data uploads/  # Ubuntu/Debian
# или
chown -R apache:apache uploads/       # CentOS
```

3. Проверьте лог-файлы PHP на наличие ошибок

### Конвертация слишком медленная

Для больших видео конвертация может занимать время. Рекомендуется:

1. Увеличить `max_execution_time` в `.htaccess` (уже установлено 600 секунд)
2. Использовать фоновую обработку через cron
3. Использовать более быстрый preset: `-preset fast` или `-preset veryfast`

### Недостаточно места на диске

Во время конвертации требуется место для:
- Оригинального файла (временно)
- Конвертированного файла

Убедитесь, что на сервере достаточно свободного места (минимум 5GB).

## Альтернативы FFmpeg

Если установка FFmpeg невозможна, рассмотрите:

1. **Cloudinary** - облачный сервис обработки медиа
2. **AWS MediaConvert** - конвертация на стороне AWS
3. **Вручную конвертировать видео** перед загрузкой через:
   - HandBrake (бесплатно, Windows/Mac/Linux)
   - Online video converter
   - Adobe Media Encoder
