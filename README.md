# 🎂🔥 Сайт Кондитерки и Фаершоу

Полнофункциональный веб-сайт для кондитерской и огненного шоу с админ-панелью, системой заказов, чатом и конструктором тортов.

## 📋 Возможности

### Раздел Кондитерка:
- ✅ Каталог товаров с категориями (торты, пирожные, капкейки)
- ✅ Подробные карточки товаров (фото, видео, описание, ингредиенты, вес, цена)
- ✅ Конструктор тортов (выбор основы, начинки, крема, украшений)
- ✅ Чат с кондитером (с возможностью отправки фото)
- ✅ Онлайн форма заказа

### Раздел Фаершоу:
- ✅ Портфолио выступлений (фото/видео)
- ✅ Описание программ и номеров
- ✅ Конструктор заказа (выбор программы, количество артистов)
- ✅ Онлайн форма заказа

### Админ-панель:
- ✅ Авторизация администраторов
- ✅ Управление товарами и категориями
- ✅ Управление ингредиентами для конструктора
- ✅ Управление программами и портфолио фаершоу
- ✅ Просмотр и обработка заказов
- ✅ Чат с клиентами
- ✅ Загрузка фото и видео
- ✅ Управление настройками сайта

## 🛠 Технологический стек

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)

## 📦 Установка

### Требования:
- PHP 7.4 или выше
- MySQL 5.7+ или MariaDB 10.11+
- Apache/Nginx с поддержкой mod_rewrite
- Расширения PHP: PDO, PDO_MySQL, GD, mbstring, fileinfo

### Шаги установки:

#### 1. Загрузите файлы на сервер

```bash
# Загрузите все файлы в корневую директорию вашего веб-сервера
# Обычно это /var/www/html или /home/user/public_html
```

#### 2. Создайте базу данных

```sql
CREATE DATABASE confectionery_fireshow CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 3. Импортируйте структуру БД

```bash
mysql -u your_username -p confectionery_fireshow < database/schema.sql
```

Или через phpMyAdmin:
- Откройте phpMyAdmin
- Выберите созданную базу данных
- Перейдите во вкладку "Импорт"
- Выберите файл `database/schema.sql`
- Нажмите "Вперед"

#### 4. Настройте подключение к БД

Отредактируйте файл `config/database.php`:

```php
define('DB_HOST', 'localhost');        // Хост БД
define('DB_NAME', 'confectionery_fireshow');  // Имя БД
define('DB_USER', 'your_username');    // Пользователь БД
define('DB_PASS', 'your_password');    // Пароль БД
```

#### 5. Настройте права доступа

```bash
# Создайте директории для загрузки файлов
mkdir -p uploads/products uploads/portfolio uploads/chat uploads/videos

# Установите права доступа
chmod 755 uploads
chmod 755 uploads/products uploads/portfolio uploads/chat uploads/videos
```

#### 6. Настройте веб-сервер

##### Apache (.htaccess уже настроен)

Убедитесь что `mod_rewrite` включен:

```bash
sudo a2enmod rewrite
sudo systemctl restart apache2
```

##### Nginx

Добавьте в конфигурацию:

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}

location ~ \.php$ {
    fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
    fastcgi_index index.php;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
```

## 🔐 Доступ к админ-панели

**URL**: `http://ваш-домен.ru/admin/`

**Дефолтные учетные данные**:
- Логин: `admin`
- Пароль: `admin123`

⚠️ **ВАЖНО**: Сразу после установки измените пароль администратора!

### Смена пароля:

1. Сгенерируйте хеш нового пароля:

```php
<?php
echo password_hash('ваш_новый_пароль', PASSWORD_DEFAULT);
?>
```

2. Обновите пароль в БД:

```sql
UPDATE users SET password = 'ваш_хеш' WHERE username = 'admin';
```

## 📝 Управление контентом

### Добавление товаров (Кондитерка):

1. Войдите в админку
2. Перейдите в "Товары"
3. Нажмите "Добавить товар"
4. Заполните все поля:
   - Название
   - Категория
   - Описание
   - Ингредиенты (через запятую)
   - Вес
   - Цена
   - Загрузите фото/видео
5. Сохраните

### Добавление ингредиентов для конструктора:

1. Перейдите в "Ингредиенты"
2. Нажмите "Добавить ингредиент"
3. Укажите тип (основа, начинка, крем, украшение, топпинг)
4. Название и цену
5. Сохраните

### Добавление программ фаершоу:

1. Перейдите в "Программы"
2. Нажмите "Добавить программу"
3. Заполните данные о программе
4. Укажите цену за артиста
5. Загрузите фото/видео

### Добавление в портфолио:

1. Перейдите в "Портфолио"
2. Нажмите "Добавить"
3. Загрузите фото или видео
4. Добавьте описание
5. Сохраните

## 🐛 Решение проблем

### Ошибка подключения к БД:
- Проверьте данные в `config/database.php`
- Убедитесь что MySQL запущен
- Проверьте права пользователя БД

### Не загружаются изображения:
- Проверьте права доступа к папке `uploads/`
- Убедитесь что расширение GD установлено
- Проверьте `upload_max_filesize` в `php.ini`

### 404 ошибки на внутренних страницах:
- Убедитесь что `mod_rewrite` включен (Apache)
- Проверьте конфигурацию Nginx
- Проверьте наличие `.htaccess`

### Чат не работает:
- Проверьте что сессии PHP работают
- Проверьте права на папку `uploads/chat/`
- Откройте консоль браузера для проверки JS ошибок
