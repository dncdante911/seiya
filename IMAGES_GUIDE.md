# 📸 Инструкция по добавлению фоновых изображений на главную страницу

Главная страница сайта поддерживает красивые фоновые изображения для каждого раздела (Кондитерка и Фаершоу).

## 🎨 Как добавить фоновые изображения:

### Шаг 1: Подготовьте изображения

Рекомендуемые параметры:
- **Размер**: минимум 1920x1080 пикселей
- **Формат**: JPG или PNG
- **Вес**: до 500 КБ (оптимизируйте изображения для веб)

**Для кондитерки**: Фото красивого торта, пирожных или кондитерских изделий
**Для фаершоу**: Фото огненного шоу, артистов с огнем

### Шаг 2: Загрузите изображения на сервер

Загрузите изображения в папку `/uploads/`:

```bash
# Загрузите файлы через FTP/SFTP или используйте команду
cp ваше-фото-торта.jpg /path/to/seiya/uploads/confectionery-bg.jpg
cp ваше-фото-огня.jpg /path/to/seiya/uploads/fireshow-bg.jpg
```

**Важно**: Названия файлов должны быть именно:
- `confectionery-bg.jpg` - для раздела кондитерки
- `fireshow-bg.jpg` - для раздела фаершоу

### Шаг 3: Готово!

После загрузки файлов обновите страницу - изображения автоматически появятся на фоне разделов!

## 🎭 Альтернативный способ (если хотите другие названия файлов):

Если хотите использовать свои названия файлов, отредактируйте `/index.php`:

Найдите строки (около 70-77):

```css
.confectionery-section {
    background: linear-gradient(135deg, rgba(255, 107, 157, 0.95) 0%, rgba(255, 140, 66, 0.95) 100%),
                url('uploads/confectionery-bg.jpg') center/cover;
}

.fireshow-section {
    background: linear-gradient(135deg, rgba(255, 69, 0, 0.95) 0%, rgba(255, 99, 71, 0.95) 100%),
                url('uploads/fireshow-bg.jpg') center/cover;
}
```

Замените названия файлов на свои:

```css
.confectionery-section {
    background: linear-gradient(135deg, rgba(255, 107, 157, 0.95) 0%, rgba(255, 140, 66, 0.95) 100%),
                url('uploads/мое-фото-торта.jpg') center/cover;
}

.fireshow-section {
    background: linear-gradient(135deg, rgba(255, 69, 0, 0.95) 0%, rgba(255, 99, 71, 0.95) 100%),
                url('uploads/мое-фото-огня.jpg') center/cover;
}
```

## ✨ Без изображений

Если вы не загрузите изображения, главная страница все равно будет выглядеть красиво - будут отображаться красивые градиенты:
- Розово-оранжевый для кондитерки
- Оранжево-красный для фаершоу

## 🛠 Оптимизация изображений

Рекомендуем оптимизировать изображения перед загрузкой:

**Онлайн-инструменты:**
- [TinyPNG](https://tinypng.com/) - сжатие PNG и JPG
- [Squoosh](https://squoosh.app/) - продвинутая оптимизация
- [Compressor.io](https://compressor.io/) - простой сжиматель

**Через командную строку (ImageMagick):**
```bash
convert original.jpg -resize 1920x1080 -quality 85 confectionery-bg.jpg
convert original.jpg -resize 1920x1080 -quality 85 fireshow-bg.jpg
```

## 📐 Рекомендации по композиции

**Кондитерка:**
- Используйте светлые, аппетитные фото
- Хорошо смотрятся макро-съемки тортов
- Избегайте слишком темных фото

**Фаершоу:**
- Динамичные фото с огнем
- Контрастные, яркие изображения
- Ночные съемки выступлений

Текст и элементы будут отображаться поверх фона с полупрозрачным градиентом, поэтому не беспокойтесь о читаемости!
