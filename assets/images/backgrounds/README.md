# 📸 Фонові зображення для головної сторінки

Ця директорія містить фонові зображення для секцій на головній сторінці сайту.

## 🎯 Необхідні файли:

### 1. **confectionery-bg.jpg** - Фон для секції кондитерки
- **Розмір:** мінімум 1920x1080px (Full HD)
- **Формат:** JPG, PNG або WebP
- **Зміст:** Красиве фото тортів, тістечок, солодощів
- **Приклади:** витончені торти, макаруни, капкейки, десертний стіл

### 2. **fireshow-bg.jpg** - Фон для секції фаершоу
- **Розмір:** мінімум 1920x1080px (Full HD)
- **Формат:** JPG, PNG або WebP
- **Зміст:** Фото вогняного шоу, артистів з вогнем
- **Приклади:** фаєр-шоу на святі, вогняні кулі, яскраві виступи

## 🎨 Рекомендації по зображенням:

### Якість:
- ✅ Висока роздільна здатність (мінімум Full HD)
- ✅ Добре освітлені
- ✅ Без зернистості
- ✅ Оптимізовані по розміру (до 500KB)

### Композиція:
- ✅ Яскраві та привабливі
- ✅ Без зайвого тексту
- ✅ Центральні об'єкти добре видно
- ✅ Гарна глибина кольору

### Ефекти (автоматично додаються CSS):
- 🌫️ Blur (розмиття) - 8px
- 🎨 Кольоровий оверлей з градієнтом
- ✨ Затемнення 85% (при hover стає 70%)
- 🔆 Насичення кольорів +20%

## 📁 Як додати свої зображення:

### Варіант 1: Заміна файлів
```bash
# Покладіть свої зображення в цю папку з правильними іменами:
assets/images/backgrounds/confectionery-bg.jpg
assets/images/backgrounds/fireshow-bg.jpg
```

### Варіант 2: Інші формати
Якщо ваші файли в іншому форматі (PNG, WebP), змініть в `assets/css/main.css`:

```css
/* Для кондитерки: */
.confectionery-section {
    background-image: url('../images/backgrounds/confectionery-bg.png');
}

/* Для фаершоу: */
.fireshow-section {
    background-image: url('../images/backgrounds/fireshow-bg.png');
}
```

### Варіант 3: Зовнішні посилання
Можна використовувати зображення з інтернету:

```css
background-image: url('https://your-cdn.com/image.jpg');
```

---

## 🔧 Налаштування в CSS:

Всі налаштування знаходяться в файлі: `assets/css/main.css`

### Змінити силу blur ефекту:
```css
.confectionery-section::before {
    backdrop-filter: blur(8px);  /* Змініть 8px на інше значення */
}
```

### Змінити прозорість оверлею:
```css
.confectionery-section::before {
    opacity: 0.85;  /* 0.0 (прозоро) - 1.0 (непрозоро) */
}
```

### Змінити колір оверлею:
```css
.confectionery-section::before {
    background: linear-gradient(
        135deg,
        rgba(255, 107, 157, 0.75) 0%,  /* Рожевий */
        rgba(255, 140, 66, 0.65) 100%  /* Помаранчевий */
    );
}
```

### Змінити позицію зображення:
```css
.confectionery-section {
    background-position: center;     /* top, bottom, left, right */
    background-size: cover;          /* contain, 100%, auto */
}
```

## 🎭 Приклади ефектів:

### При наведенні курсору:
- Blur зменшується з 8px до 5px
- Прозорість оверлею зменшується з 85% до 70%
- Насичення збільшується до 140%
- Іконка збільшується та обертається
- З'являється внутрішнє свічення

### Параллакс ефект:
- Декоративні emoji рухаються за курсором
- Фонове зображення залишається на місці
- Створює відчуття глибини
