# 🔐 Инструкция по доступу к админке

## Проблема с входом в админку?

Если не получается войти в админку, выполните следующие шаги:

### Шаг 1: Проверьте подключение к БД

Откройте файл `config/database.php` и убедитесь что данные верные:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'confectionery_fireshow');
define('DB_USER', 'ваш_пользователь');
define('DB_PASS', 'ваш_пароль');
```

### Шаг 2: Импортируйте базу данных

Если вы еще не импортировали базу данных:

```bash
mysql -u root -p confectionery_fireshow < database/schema.sql
```

Или через phpMyAdmin:
1. Откройте phpMyAdmin
2. Выберите базу `confectionery_fireshow`
3. Перейдите на вкладку "Импорт"
4. Выберите файл `database/schema.sql`
5. Нажмите "Вперёд"

### Шаг 3: Создайте админа

Откройте в браузере:
```
http://ваш-сайт.com/admin/create_admin.php
```

Этот скрипт:
- Проверит подключение к БД
- Создаст админа (если его нет)
- Покажет логин и пароль

**После создания админа УДАЛИТЕ файл `admin/create_admin.php`!**

### Шаг 4: Войдите в админку

```
URL: http://ваш-сайт.com/admin/
Логин: admin
Пароль: admin123
```

⚠️ **Сразу после входа смените пароль!**

## Смена пароля админа

### Способ 1: Через phpMyAdmin

1. Сгенерируйте хеш пароля (создайте файл `generate_hash.php`):

```php
<?php
echo password_hash('ваш_новый_пароль', PASSWORD_DEFAULT);
?>
```

2. Откройте phpMyAdmin
3. Выберите таблицу `users`
4. Найдите пользователя `admin`
5. Замените значение поля `password` на сгенерированный хеш
6. Удалите `generate_hash.php`

### Способ 2: Через SQL

```sql
UPDATE users
SET password = '$2y$10$ваш_хеш_пароля'
WHERE username = 'admin';
```

## Часты проблемы

### Ошибка "Помилка підключення до БД"

**Причина:** Неверные данные подключения к БД

**Решение:**
1. Проверьте `config/database.php`
2. Убедитесь что MySQL/MariaDB запущен
3. Проверьте права пользователя БД

### Ошибка "Невірний логін або пароль"

**Причина:** Админ не создан или неверный пароль

**Решение:**
1. Используйте `admin/create_admin.php` для создания админа
2. Проверьте что таблица `users` существует и содержит запись

### Пустая страница или ошибка 500

**Причина:** Синтаксическая ошибка PHP или проблема с сессиями

**Решение:**
1. Проверьте логи ошибок PHP (`error_log`)
2. Убедитесь что на сервере установлен PHP 7.4+
3. Проверьте права на папку для сессий

## Безопасность

🔒 **Рекомендации:**

1. **Сразу смените пароль** после первого входа
2. **Удалите `create_admin.php`** после использования
3. **Используйте сложные пароли** (минимум 12 символов)
4. **Настройте HTTPS** для защиты данных
5. **Ограничьте доступ к `/admin/`** через `.htaccess`:

```apache
# /admin/.htaccess
<Files "*.php">
    Require ip ваш.ip.адрес
</Files>
```

6. **Делайте резервные копии БД** регулярно

## Контакты

Если возникли проблемы:
1. Проверьте логи ошибок PHP
2. Проверьте логи веб-сервера (Apache/Nginx)
3. Убедитесь что все требования выполнены (см. README.md)

**Требования:**
- PHP 7.4+
- MySQL 5.7+ / MariaDB 10.11+
- Расширения: PDO, PDO_MySQL, GD, mbstring, fileinfo
