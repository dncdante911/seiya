# ⚠️ ВАЖНО: Почему MKV не работает в браузере

## 🚨 Главная проблема

**MKV, AVI, MOV и другие форматы НЕ ПОДДЕРЖИВАЮТСЯ веб-браузерами!**

Даже если файл загружается на сервер без ошибок, **браузер не сможет его воспроизвести**.

## 🌐 Что поддерживают браузеры?

### ✅ Работают отлично:
- **MP4** (с кодеком H.264) - рекомендуется!
- **WebM** (с кодеком VP8/VP9)
- **OGG** (с кодеком Theora)

### ❌ НЕ работают:
- **MKV** - контейнер, не поддерживается браузерами
- **AVI** - старый формат Windows
- **MOV** - формат QuickTime
- **WMV** - формат Windows Media
- **FLV** - формат Flash

## 🔍 Техническая информация

### Что такое MKV?
MKV (Matroska) - это **контейнер** для видео, как ZIP-архив. Внутри может быть видео в любом кодеке (H.264, H.265, VP9 и т.д.).

### Почему браузер не воспроизводит?
1. **Браузер не понимает контейнер MKV** - он ожидает MP4, WebM или OGG
2. **Даже если внутри H.264** - браузер все равно откажется воспроизводить
3. **HTML5 стандарт** поддерживает только MP4, WebM, OGG

### Проверка поддержки:
```javascript
var video = document.createElement('video');
console.log(video.canPlayType('video/mp4'));  // "probably" ✅
console.log(video.canPlayType('video/webm')); // "probably" ✅
console.log(video.canPlayType('video/x-matroska')); // "" ❌ (MKV)
```

## 🛠️ Решения

### Решение 1: Конвертировать вручную (БЫСТРО)

**Рекомендуемые программы:**

#### HandBrake (бесплатно, лучший вариант)
1. Скачать: https://handbrake.fr/
2. Открыть MKV файл
3. Выбрать пресет: **"Fast 1080p30"**
4. Формат: **MP4**
5. Нажать **Start Encode**
6. Получить MP4 файл → загрузить на сайт ✅

**Время:** ~2-5 минут для видео 1GB

#### Онлайн конвертеры:
- **CloudConvert** - https://cloudconvert.com/ (до 1GB бесплатно)
- **Online-Convert** - https://www.online-convert.com/

### Решение 2: Установить FFmpeg (АВТОМАТИЧЕСКИ)

FFmpeg будет автоматически конвертировать любые видео при загрузке.

**Шаги:**

1. **Установить FFmpeg на сервере:**
   ```bash
   # Ubuntu/Debian
   sudo apt update
   sudo apt install ffmpeg -y

   # Проверка
   ffmpeg -version
   ```

2. **Включить в коде:**

   Откройте файл: `config/functions.php`

   Найдите строку **176**:
   ```php
   $ffmpegEnabled = false;
   ```

   Измените на:
   ```php
   $ffmpegEnabled = true;
   ```

3. **Готово!**
   - Загружаете MKV → автоматически конвертируется в MP4
   - Видео работает во всех браузерах ✅

**Подробная инструкция:** см. файл `FFMPEG_INSTALL.md`

## 🎯 Рекомендации

### Для лучшего опыта:

1. **Используйте MP4 (H.264)**
   - Лучшая совместимость
   - Поддержка всех браузеров и устройств
   - Оптимальное соотношение качество/размер

2. **Параметры кодирования:**
   - **Кодек:** H.264
   - **Профиль:** High
   - **Уровень:** 4.1
   - **Битрейт:** 2-5 Mbps для 1080p
   - **Аудио:** AAC, 128-192 kbps

3. **Оптимизация для веба:**
   - Добавьте **faststart** флаг (для потоковой загрузки)
   - Используйте **двухпроходное кодирование** для лучшего качества
   - Не превышайте **FullHD (1920x1080)** без необходимости

## ❓ Часто задаваемые вопросы

### Q: Почему я получаю ошибку "No compatible source"?
**A:** Браузер не поддерживает формат файла. Конвертируйте в MP4.

### Q: Файл загружается, но не воспроизводится
**A:** Загрузка ≠ воспроизведение. Браузер может скачать MKV, но не может его воспроизвести.

### Q: У меня есть MKV с H.264 внутри, почему не работает?
**A:** Браузер не понимает **контейнер MKV**, даже если внутри подходящий кодек.

### Q: Как долго конвертируется видео с FFmpeg?
**A:** Примерно в реальном времени. Видео длиной 5 минут конвертируется ~3-7 минут.

### Q: Потеряется ли качество при конвертации?
**A:** Минимально. При правильных настройках (CRF 23) качество почти идентично оригиналу.
